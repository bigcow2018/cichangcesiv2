出现「不支持磁力计」时：
1. 必须用 Google Chrome（应用商店搜 Chrome，开发者 Google LLC）
2. 必须用 https:// 打开（GitHub Pages），不能是文件或 http
3. 不要用微信 / QQ / 系统浏览器 / 小米浏览器打开
4. Chrome 地址栏输入 chrome://flags，搜索 Generic Sensor，若有则启用相关项后重启
5. 部分国产定制 Chrome 删掉了磁力计 API，可换另一台安卓或原版 Chrome 试
6. iPhone 网页通常无法读 μT
